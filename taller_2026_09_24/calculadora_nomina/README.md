# Calculadora de Nómina Colombiana

**Estudiante:** [escribe tu nombre completo]  
**Código:** [escribe tu código]

Aplicación Android de práctica con Kotlin y Jetpack Compose para estimar una nómina mensual de Colombia usando **únicamente el modelo simplificado del taller de septiembre de 2026**. Calcula horas extra, auxilio de transporte, aportes y salario neto. No sustituye una liquidación laboral real.

## Ejecutar

Abre este proyecto en Android Studio, selecciona un emulador o teléfono Android (API 26 o posterior) y ejecuta `app`. Para pruebas locales: `./gradlew.bat :app:testDebugUnitTest :app:assembleDebug` en Windows.
